FASE 2 - RASTREO ESPACIAL:
──────────────────────────
1. Match detections to objects via:
   - Centroid distance (euclidean)
   - IOU overlap (intersection over union)
   
2. Update matched object:
   - centroid → current position
   - frames → +1
   - disappeared → reset to 0
   
3. Register new:
   - New object_id
   - Track from birth frame
   
4. Mark unmatched:
   - disappeared → +1
   - Remove if disappeared > max (30 frames)
   
5. Deduplicate:
   - if object_id not in logged_ids:
   -     AND frames >= 3:
   -         save_plate()
   -         logged_ids.add(object_id)
