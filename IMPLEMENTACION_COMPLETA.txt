��� ARQUITECTURA TÉCNICA:
═════════════════════════════════════════════════════════════════════════════

PIPELINE:

   ENTRADA (Frame OpenCV)
        ↓
   [YOLO Detection] → Bounding boxes
        ↓
   [Tracker.update] → Object IDs + tracking
        ↓
   [OCR Tesseract] → Placa text
        ↓
   [Deduplication] → Si ID nuevo AND frames >= 3
        ↓
   [Logging] → Save a detecciones.txt
        ↓
   [Display] → Overlay en video + HUD
        ↓
   SALIDA (Placa grabada)


ALGORITMO DE MATCHING:

   Entrada: detections_this_frame
        ↓
   1. Calcular centroides & distancias
   2. Calcular IOU matrix
   3. Combinar: distancia + IOU penalty
   4. Greedy assignment (O(N log N))
        ↓
   5. Update matched objects
   6. Register new objects
   7. Mark disappeared objects
   8. Remove if disappeared > max
        ↓
   Salida: tracked_objects con IDs

��� CONCEPTOS TÉCNICOS:
═════════════════════════════════════════════════════════════════════════════

CENTROID MATCHING:
   • Calcula centro de cada caja: (x1+x2)/2, (y1+y2)/2
   • Distancia Euclideana: sqrt((x2-x1)² + (y2-y1)²)
   • Rápido: O(N log N), ideal para video real-time

IOU (INTERSECTION OVER UNION):
   • Fórmula: Area_intersect / Area_union
   • Rango: 0.0 (no overlap) - 1.0 (identical)
   • Detecta cambios de tamaño/transformación

GREEDY ASSIGNMENT:
   • No es óptimo global (Hungarian O(N³))
   • Pero es suficiente para tracking (O(N log N))
   • Mejor para tiempo real

GRACE PERIOD:
   • Mantiene objeto vivo 30 frames sin detección
   • A 30 FPS = 1 segundo de tolerancia
   • Maneja oclusiones, lluvia, reflejo

OBJECT PERSISTENCE:
   • Mismo vehículo = mismo ID entre frames
   • Permite deduplicación por ID
   • Prepara para Fase 3 (clasificación)
