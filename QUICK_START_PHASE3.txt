## Troubleshooting

### Issue: GUI won't start
**Solution**: Check Python virtual environment
```bash
venv\Scripts\activate
python -c "import tkinter; print('OK')"
```

### Issue: No video feed
**Solution**: Check Hikvision camera
```bash
ping 10.10.7.224
# Should respond with pings
```

### Issue: FPS too slow
**Solution**: Skip every other frame
```python
# Edit capture_thread_func():
if frame_count % 2 == 0:  # Classify every 2nd frame
    classify_tracked_objects()
```

### Issue: Classification always "Unknown"
**Solution**: Check PyTorch installation
```bash
python -c "import torch; print(torch.__version__)"
# Should show 2.9.0+cpu
```

## Performance Tips

### For Better Speed
- Use frame skipping: `if frame_count % 2 == 0:`
- Reduce resolution: Change FRAME_WIDTH/HEIGHT in config
- Disable color processing: Use grayscale if supported

### For Better Accuracy
- Use GPU if available: Set `device='cuda'` in classifier.py
- Fine-tune ResNet50: Requires 10K+ vehicle images
- Use ensemble: Combine multiple classifiers

### For Production
- Monitor memory usage: `tasklist | findstr python`
- Log to external server: Add database integration
- Set up alerts: Email on infraction detection
